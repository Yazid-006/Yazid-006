## Featured project

### QuizZy — real-time multiplayer quiz

<!-- Un GIF vaut bien mieux qu'un PNG ici : le temps réel ne se voit pas sur une image fixe. -->
<!-- <img src="assets/quizzy.gif" width="100%" alt="QuizZy — live multiplayer room with scores updating in real time"> -->

Multiplayer quiz rooms where every player sees the same question at the same moment and the leaderboard moves as answers come in. A host controls the pace; players join with a room code.

The interesting part isn't the quiz — it's keeping dozens of clients in sync without polling the server to death. Laravel Reverb handles the WebSocket layer: the host broadcasts state transitions, clients react, and scoring is settled server-side so a modified client can't cheat its way up the board. Disconnects and rejoins resolve back to the room's current state rather than dropping the player.

This architecture is what I now reuse for any real-time feature I build.

`Laravel` `Vue 3` `TypeScript` `Reverb` `MySQL`

**[Live demo](https://quiz-zy-ebon.vercel.app/)**
